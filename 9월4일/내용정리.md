- 데이터 분석은 프로세스다.
- 입수 데이터는 충분히 의심하라
- 모델 개발 보다 모델 설계가 더 중요
  - 분석 모집단 구성, segment/target/feature 정의, 분석기법/검증 및 평가 방법 설계 등
- 모델 학습보다 모델 검증 및 평가가 더 중요하다
- 모델 성능은 피쳐 성능에 달려있다
- 높은 성능의 모델 보다 중요한 것은 잘쓰이는 모델이다.

- 좋은 모델링은 좋은 알고리즘을 찾는 문제가 아니라, 데이터를 제대로 이해하고 문제를 설계한 뒤 적절한 Feature와 평가 방법을 통해 실제로 활용 가능한 모델을 만드는 과정

- 실습

| Random Forest       | XGBoost                     | 역할                               |
| ------------------- | --------------------------- | ---------------------------------- |
| `n_estimators`      | `n_estimators`              | 트리 개수                          |
| `max_depth`         | `max_depth`                 | 트리 깊이                          |
| `min_samples_split` | `gamma`, `min_child_weight` | 쉽게 분할하지 못하게 제한          |
| `min_samples_leaf`  | `min_child_weight`          | 너무 작은 leaf 방지                |
| 없음                | **`learning_rate`**         | 다음 트리가 얼마나 강하게 보정할지 |
| 없음                | `subsample`                 | 각 트리가 사용하는 데이터 비율     |
| `max_features` 비슷 | `colsample_bytree`          | 사용하는 feature 비율              |

| Random Forest      | LightGBM            | 의미                  |
| ------------------ | ------------------- | --------------------- |
| `n_estimators`     | `n_estimators`      | 트리 개수             |
| `max_depth`        | `max_depth`         | 최대 깊이             |
| `min_samples_leaf` | `min_child_samples` | Leaf 최소 데이터 수   |
| `max_features`     | `colsample_bytree`  | 사용할 Feature 비율   |
| 없음               | `learning_rate`     | 트리 하나의 보정 강도 |
| 없음               | **`num_leaves`**    | 트리의 복잡도         |
| `class_weight`     | `class_weight`      | 클래스 불균형 보정    |

# 궁금한점

- 피쳐엔지니어링 + ML vs 딥러닝

| 데이터                              | 보통 유리한 접근                  |
| ----------------------------------- | --------------------------------- |
| 테이블 데이터, 수천~수십만 행       | **XGBoost / LightGBM / CatBoost** |
| 피처 수가 지나치게 많고 노이즈 많음 | Feature Selection + ML            |
| 데이터 수백만~수천만 개             | Deep Learning도 강해짐            |
| 이미지                              | Deep Learning                     |
| 텍스트                              | Deep Learning / Transformer       |
| 음성                                | Deep Learning                     |
| 시계열 raw signal                   | Deep Learning이 강한 경우 많음    |
| 일반 기업 CSV/DB 데이터             | Tree 계열이 매우 강함             |
