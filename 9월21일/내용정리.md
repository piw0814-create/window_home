- LangChain은 서로 다른 출처의 패키지들이 하나의 표준(Runnable)을 지키기 때문에 이가 맞물려 조립됨
- 패턴 4. tool
  - bind_tools()로 함수 스키마를 모델에 노출하면, 모델이 호출 여부와 인자를 스스로 판단(@tool, bind_tool(), response.tool.calls)
- 패턴 5. Retry/Fallback
  - with_retry()로 재시도 횟수를 지정하고, with_fallbacks()로 실패 시 대체 모델을 연결(with_retry(), with_fallbacks())
- 패턴 6. 복합 체인, 병렬 처리, 분기
  - RunnableParallel 로 여러 chain을 동시 실행하고, RunnableLambda로 커스텀 분기 로직을 끼워 넣는다(RunnableParallel, RunnableLambda)
