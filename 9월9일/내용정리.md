# 궁금한점

- 타입 소거?

  제네릭 안의 구체 타입 정보가 런타임에 사라지는 것
  타입 소거 = 제네릭 내부 타입 정보가 런타임에 사라짐

ParameterizedTypeReference = 그 타입 정보를 보존해서 전달

컴파일러가 .class를 만들면서 제네릭 정보를 대부분 제거한 형태로 변환한다고 이해하면 돼.
그래서 List<ActorsFilms>을 런타임에서도 정확히 알아야 할 때 ParameterizedTypeReference 같은 별도 장치가 필요한 거야.

        객체 1개 → Class
        제네릭 객체 → ParameterizedTypeReference
        단순 문자열 목록 → ListOutputConverter

- 제네릭 객체?

  < > 안에 타입을 넣는 구조
  Java가 제네릭을 “실행할 때 쓰는 정보”가 아니라 “컴파일할 때 타입 검사하는 장치”로 설계했기 때문에 컴파일 끝나면 타입 소거 문제가 일어남
