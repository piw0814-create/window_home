# 궁금한점

쿠키?
쿠키는 브라우저가 저장하고 요청 때 서버로 보내는 작은 데이터이며, 로그인 서버에서는 주로 세션 ID나 JWT를 담아 사용자를 계속 인증하는 데 사용한다.

인터페이스/추상클래스에 대한 보충 설명
자바는 기본적으로 다중상속 안됨.(상속관계과 관리가 안되기 때문) -> 개발자가 구현을 해야할 메서드만 가지고있는 묶음

| 구분               | 인터페이스                       | 추상 클래스                  |
| ------------------ | -------------------------------- | ---------------------------- |
| 핵심 목적          | 기능 계약 정의                   | 공통 상태·기능 공유          |
| 사용 문법          | `implements`                     | `extends`                    |
| 필드               | 일반 인스턴스 상태 보관에 부적합 | 인스턴스 필드 가능           |
| 생성자             | 없음                             | 있음                         |
| 일반 메서드        | 주로 계약, `default/static` 가능 | 자유롭게 구현 가능           |
| 추상 메서드        | 가능                             | 가능                         |
| 직접 객체 생성     | 불가능                           | 불가능                       |
| 한 클래스에서 사용 | 여러 인터페이스 구현 가능        | 부모 클래스 하나만 상속 가능 |

# 개인 이해 정리

실제 서비스는 AI 모델이나 서버 하나를 실행하는 것으로 끝나는 것이 아니라, 핵심 사용자와 문제, 입력 데이터, 제공 결과, 사용 위치, 비용, 보안, 장애 대응까지 포함한 전체 흐름을 먼저 설계해야 한다. 각 구성요소의 책임을 나눈 뒤 적절한 기술을 배치한다.

순수 Java로 HTTP 라우팅, 요청 파싱, 객체 생성과 연결, JDBC DB 처리, BCrypt 비밀번호 해싱, 세션·쿠키, JWT 발급과 검증을 직접 구현. 이를 통해 객체와 메서드의 호출 관계를 이해하고, Spring Boot가 반복적인 서버 설정과 객체 관리를 자동화하는 이유를 체감
