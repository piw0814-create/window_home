# 예습 요약

1. vue는 상태가 변하면 화면을 자동으로 다시 그려주는 프론트엔드 프레임워크
2. ref()는 vue가 감시할 반응형 상태를 만든다
3. v-model은 화면 입력과 javascript상태를 양방향으로 연결한다
4. computed는 상태로 값을 계산하고, watch는 상태변화 후 행동한다.
5. 화면은 component라는 작은 .vue파일들로 쪼갠다
6. 부모 -> 자식은 props, 자식 -> 부모는 emit이다.
7. router는 페이지, pinia는 전역상태, axios는 백엔드 통신을 담당한다.

# 본 수업

- vue는 MVVM 아키텍쳐 패턴을 따른다.(model(데이터), 뷰엔진이 뷰와 데이터를 연결 시켜줌)
- virtual DOM(DOM 업데이트를 모았다가 한번에 처리)
- 데이터 바인딩 : v-model directive
- componet based architecture (Props, emit)
- CSR : 브라우저가 자바스크립트를 실행하여 직접 화면을 그리는 방식(클라이언트가 직접), 서버는 json 데이터만 제공하는 형태, SPA(초기 로딩만 오래걸리고, 후엔 필요 json데이터만 받아서 빠름)
- vue router : 브라우저의 url주소와 vue컴포넌트를 연결해 주는 공식 라우팅 라이브러리
- pinia : 전역 상태 관리 라이브러리로 모든 컴포넌트가 접근할 수 있는 중앙 집중식 데이터 저장소
- axios : 벡엔드 서버(API와 순수한 데이터(JSON)만 주고 받는 통신 창구)
- vite : vue, js css파일들을 브라우저가 읽을 수 있는 최적화된 형태의 정적파일로 묶어주고, 개발 서버도 띄워주는 빌드 도구
- node.js : 빌드도구(vite)의 실행 엔진, 패키지 관리(npm/nvm), 로컬 개발 서버 구동
- SFC (.vue확장자를 가진 하나의 독립된 파일) : script setup, template, style
- v-directive! 잘 이해하기
- v-bind, v-model, v-on
- 객체(Object) 구문 패턴 기본 구조: :class="{ '클래스명': 조건불리언변수 }“
- 배열(Array) 구문 패턴 기본 구조: :class="[기본클래스변수, 조건 ? '클래스A' : '클래스B’]”
- v-if, v-show(더 빠름, DOM을 파괴 및 생성 안하기 때문)
- v-for 를 쓸때 반드시 고유한 값을 :key속성을 바인딩

{{ 변수 }}
→ HTML 태그 "내용"에 연결

v-text="변수"
→ HTML 태그 "내용"에 연결

v-html="변수"
→ HTML 태그 "내용"을 HTML로 연결

:속성="변수" (v-bind)
→ HTML 태그의 "속성"에 연결

:class는 CSS 자체를 바꾸는 게 아니라, Vue 상태에 따라 어떤 CSS 클래스 이름을 HTML 요소에 적용할지 결정한다.

:href="url"
→ href 속성을 상태와 연결

:disabled="isDisabled"
→ disabled 속성을 상태와 연결

:class="{ active: isActive }"
→ class 속성을 상태와 연결

:style은 CSS 속성값 자체를 Vue 데이터로 직접 넣는 방식

:class
→ CSS 클래스 이름을 동적으로 붙임
→ .text-danger 같은 미리 정의된 CSS 사용

:style
→ CSS 속성값을 직접 동적으로 넣음
→ color, fontSize 등을 바로 설정

# 궁금한점

화살표 함수는 자기 자신의 this를 만들지 않아서, 객체 자기 자신을 this로 접근하는 메서드에는 보통 일반 메서드 문법을 쓰는 게 좋다.
반면 Vue의 <script setup>에서는 객체의 this를 사용할 일이 거의 없어서 화살표 함수로 함수/이벤트 핸들러를 만드는 방식이 아주 자주 나옴
