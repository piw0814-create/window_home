- Axios
  - try catch finally
  - async/await와 Axios를 이용해 외부 REST API에 GET 요청을 보내고, response.data의 JSON 응답을 Vue의 ref()에 저장하여 화면에 반응형으로 표시하며, try/catch/finally로 성공·실패·로딩 상태를 처리
  - 비동기 await활용 try ... 활용

- UI 라이브러리
  - 웹 어플리케이션 구축에 필요한 공통 컴포넌트를 모듈화하여 제공하는 오픈소스 패키지
  - 버튼, 입력창, 카드, 테이블, 모달, 드롭다운, 네비게이션 등 자주 사용하는 UI를 직접 처음부터 만들지 않고 재사용 가능
  - 설치 후 필요한 컴포넌트를 import하여 사용하고, Props나 옵션을 통해 디자인과 동작을 설정

    - 이 완제품 dist 폴더 자체를 AWS S3, Nginx, Netlify, Vercel 등 정적 웹 호스팅 서버에 그대로 Upload하면, 웹 서비스 배포 파이프라인이 최종 완결된다.
- 배포과정 정리
  - ESLint와 Oxlint로 결함 가능성이 있는 코드를 검사한다.
  - Prettier로 프로젝트 전체의 코드 형식을 통일한다.
  - .env로 환경별 설정값을 관리한다.
  - 공개 변수와 서버 비밀키를 구분한다.
  - Vite가 소스 코드를 프로덕션용으로 번들링한다.
  - 완성된 결과물은 dist 폴더에 생성된다.
  - Vercel이 정적 파일과 서버 함수를 함께 배포한다.
  - GitHub를 연결하면 Push 이후 배포를 자동화한다
