# 궁금했던 점

객체 지향이라는데 이게 파이썬 클래스 이용하는거랑 다른점이 있어?

Python은 객체지향을 비교적 자유롭게 사용하고, Java는 객체지향 구조를 더 엄격하고 명확하게 강제한다.

    타입 명시, 접근권한 엄격 관리, 클래스간 관계를 더 명확하게 설계, 인터페이스가 중요, 클래스-파일-패키지 구조가 더 엄격, 클래스 상속을 하나만 받고 인터페이스는 여러개 구현

Python 클래스와 Java 클래스의 객체지향 원리는 같다. 다만 Java는 타입, 접근 권한, 인터페이스, 패키지와 객체 관계를 더 엄격하게 표현하며, Spring은 그렇게 나눈 객체들을 자동으로 생성하고 연결해주는 프레임워크다.

파이썬 클래스들로 자바들에서 쓰는거 라이브러리로 만들어서 사용하는것도 안되나?

같은 백엔드 안에서도 파이썬으로 데이터분석을 하고, 그 결과를 다시 제이슨 파일로 자바와 주고받는 것인가?

객체 안의 필드로 int i = 0을 선언했다면 메서드가 끝나도 초기화되지 않는다. 반대로 메서드 내부에 int i = 0을 선언했다면 메서드가 끝날 때 사라지고, 다음 호출 때 새로운 i = 0이 만들어진다.
