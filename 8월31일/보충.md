- 네트워크
  - 여러 컴퓨터 통신
  - 클라이언트 -> 여러 장치들 -> 서버
  - 데이터를 패킷단위로 나누어서 전달(오류 수정 쉬움), 각각 출발지ip, 목적지ip 다 적혀있음
  - 도착하면 ip:포트 로 해당 프로그램으로 전달 (포트 생략은 기본 포트로 감)
  - ip 대신 도메인 이름을 씀(DNS서버 거쳐서 ip로 변환)
  - ip주소가 항상 고정적이지 않기 때문(제한적인 ip주소를 유동적으로 제공)

- 리퀘스트
  - 매서드 : 어떤작업 (get, post, put, delete)
  - 패스 : 어떤기능을 수행할지
  - 헤더 : 요청에 대한 정보(인증 정보(권한))
  - 바디 : 보낼 데이터 (보통 get은 바디가 비어있고, post에 있음)
- 리스폰스
  - 스태이터스 : 응답 코드 - 200번대: 성공, 400번대: 요청쪽에서 확인해야할 문제, 500번대 : 서버(백엔드)쪽문제
  - 헤더 : 응답에 대한 추가 정보
  - 바디 : 실제 데이터
