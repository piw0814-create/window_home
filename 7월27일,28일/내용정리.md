kpi 조직의 목표및 성과를 계량화하여 측정, 하부 조직으로 상부조직의 kpi를 cascading

six-sigma(maic) 제조산업에서 시작된 품질 관리 활동을 고객 만족도/서비스 영역으로 확장

분석 목적과 문제 정의
분석 수행 절차
분석 결과 정리 및 활용

내가 데이터(자원)를 어떻게 보고있는지(관점)(어떤 도메인에선 어떤 데이터가 중요한지 파악), 따라서 어떤 기법을 쓸껀지 결정(통계)
개념적 정의, 분석 기법, 조작적 정의(사람이 이해하는 추상적인 개념을 컴퓨터가 계산하고 판별할 수 있는 변수·수식·조건으로 번역하는 작업)
왜 이러한 분석을 썻는지 어떤 모델이 좋은지 먼저 예측을 하라

분석 프로젝트의 6단계

    비즈니스 이해

        기업이나 현장의 문제는 무엇인가?
        분석을 통해 달성할 목표는 무엇인가?

    가설 수립·데이터 이해

        어떤 가설을 검증할 것인가?
        어떤 데이터 항목이 필요한가?

    데이터 준비

        결측치·이상치 처리
        파생변수 생성
        Feature Engineering

    분석 모델 정의

        EDA와 시각화
        알고리즘 선정
        Train·Validation·Test 데이터 구성

    모델 평가

        모델 성능과 비즈니스 활용 가능성 평가
        정확도, 재현율, 오류 유형 등을 함께 판단

    시스템 적용

        모델 배포
        성능 모니터링
        데이터 변화와 성능 저하 감지
        모델 재학습과 유지보수

기초통계

3-1. EDA

    개념적 정의와 조작적 정의(변수 정의, 분석단위 설정, 척도화)

        변수와 값의 차이
        독립변수·종속변수·매개변수·통제변수
        원천 데이터와 파생변수

    분석 단위 설정!!!

        개인별, 상품별, 기간별, 지역별 등

    데이터 척도

        이산

        연속(구간,비율(0의 의미가 있냐 없냐))

    탐색적 분석 EDA와 확증적 분석 CDA 비교

        EDA : 데이터 요약, 그래프, 재표현, 어떤 분포에 적합한지 검증, 통계적 가설 설정과정 없음

        데이터 구조/특징 이해, 변수간 관계 이해, 모델링 방향 설정

    가장 중요한 흐름

        추상적인 비즈니스 문제
        → 실제 측정 가능한 변수로 조작적 정의
        → 분석 단위와 척도 설정
        → EDA 수행

3-2. Preprocessing

    데이터 유형과 구조 확인 (매트릭스, 데이터프레임)
    데이터 품질 분석
    결측치 확인 및 처리 -> 비즈니스 관점에서 제외or대체해도 되는지 반드시 검토
    결측 행 제거와 다른 값 대체의 차이
    평균, 이동평균, 추세값 등을 이용한 대체
    이상치 확인 및 처리
    전처리로 발생할 수 있는 정보 손실과 왜곡

    결측치를 무조건 제거하는 것이 아니라, 비즈니스 관점에서 삭제해도 되는지 먼저 검토해야 함

3-3. Statistics

    데이터의 분포와 특징을 숫자로 요약

    중심: 평균, 중앙값, 최빈값
    퍼짐: 범위, 분산, 표준편차
    위치: 사분위수
    분포와 대칭성
    기술통계와 그래프를 함께 해석하는 방법

    퍼짐과 분포는 그 값만 보고 판단하는 게 아니라 비교대상과 같이 보자

3-4. 확률분포

    데이터는 같은 단위로 봐야됨

    확률과 확률변수
    이산형·연속형 확률분포
    이항분포
    정규분포
    평균과 분산에 따른 정규분포 변화
    표준화와 Z-score
    로그변환과 데이터 변환

3-5. 상관관계

    교차표
    공분산
    상관계수
    양의 상관·음의 상관·무상관
    상관계수의 크기와 방향 해석
    상관관계와 인과관계의 차이
    산점도와 상관행렬 해석

    상관관계가 있다고 해서 원인과 결과가 증명되는 것은 아니다.
    상관계수는 선형적인 관계만을 알 수 있으며, 곡선은 알 수 없음, 상관계수 수치만 보고 판단하지 말고, 그래프 분석을 병행하는것이 필요(ex.산점도 이용, 데이터분해)
    아웃라이어에 민감하게 반응하므로 제거 후 상관분석 진행하는게 좋음
    제 3의 교란 요인은 없는가???????(편상관계수, 비즈니스관점에서 해석 꼭 필요)
    시간 선/후 관계, 방향이 맞는가???

3-6. 회귀분석

    회귀 가정 : 선형성, 다중공선성(독립성)(다중공선성이 발생한 변수들 중 하나를 제거하거나 변수들을 결합하여 새로운 변수를 생성하여 다중공선성 제거), 정규성, 등분산성
    회귀선(최소제곱법)
    모델 설명력(Adj. R^2), 오차평가(RMSE, MAPE)
    결정계수 확인, F, p값
    선형 함수로는 현실적인 한계를 표현할 수 없다 -> 로지스틱 -> 분류

    주의 사항 : 회귀분석의 가정, 다중공선성, 이상치의 영향, 변수 선택


    독립변수와 종속변수 설정
    단순 선형회귀
    다중 선형회귀
    회귀식과 회귀계수
    결정계수 R^2와 조정된 결정계수
    F검정과 회귀모형의 유의성
    개별 회귀계수의 p-value
    불필요한 독립변수 제거
    선형회귀와 로지스틱 회귀 비교

    종속변수가 매출액처럼 연속형이면 선형회귀를 사용하고, 대출 승인 여부처럼 범주형이면 로지스틱 회귀를 사용하는 식으로 구분
