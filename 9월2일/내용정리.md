# 궁금한점

- 실제 코드에서 He Initializion부분은 잘 못 본것 같은데?

ReLU 계열 활성화 함수와 같이 쓰는 게 대표적
ReLU는 음수 영역을 0으로 잘라버리니까, 층을 계속 통과하면서 값의 분산이 너무 줄어들지 않도록 초기 weight의 크기를 적절히 잡아줘야함

요즘은 직접 초기화를 코드로 지정하지 않는 경우도 많다. PyTorch의 nn.Linear, nn.Conv2d 같은 레이어들이 기본 초기화를 이미 적용

- XGBoost / LightGBM 의 성능비교 예상

LightGBM은 대용량 Tabular에서 빠르고 효율적으로 높은 성능을 내기 쉬운 편이고,
XGBoost는 상대적으로 안정적이고 튜닝했을 때 강한 경우가 많다.

LightGBM = 빠르고 공격적인 Boosting
XGBoost = 조금 더 보수적이고 안정적인 Boosting
정확도는 어느 쪽이 무조건 우위라고 할 수 없음

LightGBM이 성능이 더 좋아 보이는 이유 중 하나는 기본 설정만으로도 leaf-wise 특성 덕분에 복잡한 패턴을 빠르게 잡아내는 경우가 많기 때문

- 컨볼루션으로 차원축소를 하면 되는데 굳이 풀링을 쓰는이유

pooling은 이미 추출된 특징을 단순 요약해서 줄인다.
굳이 pooling을 쓰냐면, 가장 큰 이유는 위치 변화에 덜 민감하게 만들기 위해서
무엇보다 학습 파라미터가 없어서 단순하고 계산도 쌈.

MaxPooling은 정보를 많이 버리긴 하지만,

정확한 위치보다는
"이 주변에 강한 특징이 있었는가?"를 남기는 성질이 이미지 분류에서는 오히려 좋은 inductive bias가 될 수 있음. 특히 이런 단순한 28×28 이미지에서는 복잡하게 다운샘플링 방법까지 학습시키는 것보다 MaxPool이 충분히 잘 먹힐 수 있다.

- 이상 탐지 모델 : 오토인코더 vs 머신러닝

| 상황                                         | 많이 쓰는 방법                           |
| -------------------------------------------- | ---------------------------------------- |
| 표형 데이터, 피처가 이미 잘 정리됨           | **Isolation Forest, One-Class SVM, LOF** |
| 데이터가 적음                                | 전통 ML이 유리                           |
| 고차원 센서/이미지/오디오                    | **Autoencoder 계열**이 강함              |
| 정상 데이터는 많고 비정상 데이터가 거의 없음 | AE, One-Class 계열                       |
| 해석 가능성 중요                             | 통계/ML 쪽                               |
| 복잡한 비선형 패턴                           | AE 등 딥러닝 쪽                          |

전통 ML

Isolation Forest
→ 이상치는 다른 데이터와 빨리 분리될 것이다

One-Class SVM
→ 정상 데이터가 존재하는 영역의 경계를 학습

LOF
→ 주변 데이터에 비해 밀도가 이상하게 낮으면 이상

PCA
→ 정상 데이터의 주요 구조에서 크게 벗어나면 이상

그리고 현실에서는 둘을 섞기도 해.

        Raw 센서 데이터
            ↓
        Autoencoder / CNN
        특징 벡터 추출
            ↓
        Isolation Forest
            ↓
        이상 여부

- 비전모델과 llm한테 이미지 던져서 분석하라고 하는것의 차이?

|                     | GPT 같은 VLM       | YOLO / SAM                |
| ------------------- | ------------------ | ------------------------- |
| 주목적              | **이해·설명·추론** | **정확한 시각 인식 작업** |
| 출력                | 주로 자연어        | Box / Mask / 좌표         |

요즘 비전이 재미있는 게 전문 Vision 모델과 GPT 같은 멀티모달 모델의 경계가 점점 합쳐지고 있는 것
VLM = 보고 + 언어와 연결하고 + 추론한다
그래도 아직 픽셀 단위 정밀 작업·실시간 detection은 SAM/YOLO 같은 전문 모델, 전체 상황을 이해하고 질문에 답하는 건 GPT 같은 VLM이라고 구분
